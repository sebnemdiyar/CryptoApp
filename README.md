## Crypto App
Bu proje, güncel kripto para piyasası verilerini takip etmenizi, fiyat grafiklerini incelemenizi ve kullanıcı dostu bir arayüz üzerinden piyasa hareketlerini gözlemlemenizi sağlayan modern bir web uygulamasıdır.

## Özellikler
Kripto para birimlerinin güncel liste görünümü ve anlık fiyat takibi
Detaylı fiyat grafikleri ile geçmiş verilerin ve trendlerin analizi
Responsive ve modern tasarımı sayesinde tüm cihazlarda sorunsuz kullanım
Hızlı ve optimize edilmiş yönlendirme yapısı

## Kullanılan Teknolojiler
React Router DOM
Lucide React
Tailwind CSS
Axios
Chart.js
React Chart.js
